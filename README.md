# CyberFun Academy

This website was created for educational purposes, inspired by my personal experience.
In my town, many hacking activities occur frequently, causing residents to suffer losses of money and social media accounts simply because of opening a harmful message.
To improve people’s awareness, I built this fun and engaging website where students, children, and everyone can learn 
how to be secure and cautious before interacting with any suspicious messages.

---

## Purpose

- Raise cybersecurity awareness  
- Provide a fun and educational platform  
- Help people develop safer online habits  

---

## Usage

Open this website in any modern browser and explore the interactive activities designed to increase your cybersecurity knowledge.
